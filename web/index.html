By tier

Subscriptions

Each seat is flat-rate — billed monthly, not per token — so it is metered on its own line: what its traffic would have cost billed per token, against the fixed fee that displaced that bill. Saved is the difference; it reads red until a seat's use earns its fee back. Metered API traffic is the headline above; this is a separate track.

Services

Capability backends. The gateway registers a row and health-checks it; it does not run the sandbox, tool, guard, or browser.

Providers

What this build can reach, beside what you have registered. An API key and a subscription seat are different credentials, and most providers take one and not the other. "Import only" means the seat imports and refreshes but nothing serves inference on it — the credential sits stored and idle. "Prohibited" is a policy decision with the provider's own terms behind it, not a missing feature; "no" is simply that nobody has written an importer.

Models

The id is the address: clients send it, a ladder names it, and the ledger records spend under it, so it never changes. The label is only a name — rename it freely. Leave it empty and the placeholder is what a picker shows.
